# 数据质量检查清单

## 结构

- 行数 / 列数是否与描述一致
- 字段类型：数字列里是否有文本、日期列是否可解析
- 单位是否统一（元 / 万元、秒 / 毫秒、百分比 / 小数）

## 缺失

- 缺失比例：按列统计，超过 30% 的列要单独说明
- 缺失模式：随机缺失还是集中在某个时间段 / 分组
- 处理方式：删除 / 填充 / 保留并标注，写清理由

## 重复

- 主键是否唯一；重复行是否应该合并
- 同一实体多次出现时，用哪个时间点为准

## 异常值

- 数值范围是否合理（负数的时长、超大的金额）
- 用分位数看尾部，不要只用最大最小值
- 异常是录入错误还是真实极端值，给出判断依据

## 口径

- 统计期是否完整（首尾是否缺天 / 缺月）
- 分母是什么：人数 / 订单数 / 金额
- 同一指标在不同表里是否一致

## 校验

- 分组求和 = 总量
- 抽样 5–10 行回原始数据核对
- 关键结论至少用两种方式算一遍
