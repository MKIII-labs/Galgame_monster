# 审查清单（按严重度展开）

## 1. 正确性

- 空值 / 缺省值：变量、返回、配置项为空时是否仍成立
- 边界：0、1、-1、空集合、超大输入、超长字符串
- 并发：共享状态是否加锁；锁内是否有阻塞调用；重入是否安全
- 异常：抛错后资源是否释放；错误是否被静默吞掉
- 幂等：重试 / 重复提交会不会产生第二份数据
- 时间与精度：时区、夏令时、浮点比较、金额舍入

## 2. 兼容性

- 接口签名：新增必填参数会破坏谁
- 数据格式：字段改名 / 类型变化是否需要迁移
- 旧数据：缺字段的历史记录能否正常读取
- 平台：Windows / Linux 路径、大小写、换行、编码
- 依赖：版本锁定、可选依赖缺失时的降级

## 3. 安全

- 输入校验：长度、类型、白名单
- 路径：`..`、绝对路径、符号链接
- 注入：SQL / Shell / 模板 / 日志注入
- 权限：越权读写、默认权限过大
- 密钥：硬编码、日志打印、错误信息回显

## 4. 可维护性

- 重复逻辑是否可以用一处参数化
- 隐藏耦合：改 A 却必须同步改 B
- 命名与职责是否一致
- 死代码 / 调试残留

## 5. 风格（最低优先级）

- 只在项目已有规范冲突时提；个人偏好不列为问题
