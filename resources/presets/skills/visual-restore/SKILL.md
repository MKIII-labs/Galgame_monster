## 目标

把「看起来一样」变成可检查的差距清单：先量，再改，按最大差距迭代。

## 何时用

- 有参考物（图 / 设计稿 / 截图 / 已有产物），要复刻或做到接近
- 用户说「不像」「样式不对」「比例怪」「颜色不对」

## 步骤

1. 明确参考物与产物：一张参考对一张产物；多视图就逐组配对；没有参考物先要一张
2. 先做最小可交付切片，再谈细节：整体结构与比例优先于局部细节
3. 用 image_compare 建基线：记录总分与各项指标（轮廓、比例、主色、结构、局部差）
4. 按差距最大的 1–2 项迭代，每次只改一类；改完重新对照，保留前后分数
5. 指标之外用 see_image 补充语义差异（文字、含义、特征是否缺失）；
   视觉模型的结论要能用指标或原图复核，不能直接当事实
6. 报告：当前分数、剩余差距、哪些是外部限制（缺素材 / 平台差异 / 需人工审美）

## 输出

- 对照指标（前后）+ 差距清单（位置 + 现象 + 处理）

## 禁止

- 凭记忆调样式 / 凭想象描述产物
- 机检通过就说还原完成（存在「全部通过但看起来不像」）
- 为了过检而放宽验收阈值；阈值应来自参考物或用户要求
- 只修毫米级贴合，不处理主导观感的差距
