# 对照指标口径

## 先固定测量条件

- 同一尺寸、同一缩放、同一设备像素比
- 同一背景与字体；动效暂停
- 参考图与产物都保存原图，不用压缩截图对比

## 常用指标

| 指标 | 看什么 | 常见误判 |
| --- | --- | --- |
| 轮廓 / 边缘 | 整体形状是否一致 | 抗锯齿会让边缘分数偏低 |
| 比例 | 主要区块的宽高比 | 缩放后比较会失真 |
| 主色 | 面积最大的几种颜色 | 渐变区域取色点不同结果差很大 |
| 结构 | 分隔线、留白、对齐 | 局部元素差异会稀释整体分 |
| 局部差 | 文字、图标、细节 | 字体缺失会被当成设计错误 |

## 迭代策略

1. 先修「主导观感」的差距（整体比例、主色、布局）
2. 再修局部细节（图标、圆角、阴影）
3. 每次只改一类，改完记录分数
4. 分数不再上升时，检查是否到了外部限制

## 什么时候不能只看指标

- 文字内容 / 语义不同
- 参考物本身有压缩噪声
- 需要人工审美判断（风格化插画、氛围）
