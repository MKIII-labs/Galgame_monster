# 素材流水线

先摸清素材，再转换 / 打包 / 内联，最后按清单验收；不要凭想象处理资源。

## 何时用

- 需要扫描素材目录、统计尺寸 / 格式 / 重复 / 体积
- 需要统一图片格式、缩放、压缩质量
- 需要把多帧图片打成图集，或把素材内联进 JSON / JS
- 需要检查 3D 模型的三角面、包围盒、材质、贴图、法线 / UV
- 改完素材后需要确认没有缺失、尺寸变化或图集缺口

## 不适用

- 纯代码逻辑、接口、算法任务
- 没有任何素材文件、只需要写文案或设计说明
- 只做一次性的图片查看，不需要产出新文件

## 核心步骤

1. **先扫描**：用 `asset_scan`（或 `asset(action=scan)`）读取目录，记录图片尺寸 / 格式 / 哈希 / 重复、音频、模型、总大小；需要后续验收时把清单写到 `assets.json`。
2. **定目标再转换**：需要统一格式 / 尺寸时用 `asset_convert`（`asset(action=convert)`）；明确目标格式、宽高、质量。**不要覆盖原图**，输出到新目录或新文件名。
3. **图集打包**：多帧 / 图标用 `asset_atlas`（`asset(action=atlas)`），生成 PNG + JSON 帧映射；保留 padding（默认 2），避免采样出血。
4. **内联素材**：需要单文件交付、素材在沙箱外或部署不想带独立文件时，用 `asset_inline`（`asset(action=inline)`）输出 JSON 或 JS（`window.__ASSETS__`）；需要控制体积时设 `max_kb`。
5. **3D 先体检**：处理 glTF / GLB / OBJ 时先用 `mesh_inspect`（`asset(action=mesh)`）：节点、三角面、顶点、包围盒、材质与贴图引用、法线 / UV 缺失、贴图文件是否存在。**体检通过再截图验画面**。
6. **按清单验收**：改完用 `asset_validate`（`asset(action=validate)`）检查文件是否存在、尺寸是否变化、图集文件是否缺失；清单路径与扫描时保持一致。
7. **记录产物**：在回答里写清清单、转换 / 图集 / 内联产物路径，以及哪些格式或平台差异没有验证。

## 输出格式

- 扫描结果：素材数量、异常项、清单路径
- 产物：转换 / 图集 / 内联文件路径
- 校验：通过项、缺失项、尺寸变化项
- 未覆盖：未检查的格式、平台或外部依赖

## 失败处理

- 缺素材 / 缺权限 / 格式不支持：列出缺什么、需要用户提供什么，不要用占位图假装完成。
- `mesh_inspect` 报贴图缺失或法线 / UV 缺失：先补文件或修模型，再截图；不要用截图掩盖几何问题。
- `asset_validate` 失败：按清单定位是文件消失、尺寸变化还是图集缺口；不要直接放宽清单。
- 体积超限：优先缩尺寸 / 降质量 / 拆图集，不要静默删除素材。

## 常见错误

- 不扫描直接转换，结果漏图或重复图
- 覆盖原图，导致无法回滚
- 图集不带 padding，边缘出血
- 只截图看 3D 模型，不跑 `mesh_inspect`
- 内联时不设体积上限，产物过大
- 验收时换了清单路径，等于没验
