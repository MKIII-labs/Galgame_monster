## 目标

把长文压成能直接用的四块：结论、依据、待办、风险。

## 何时用

- 用户贴长文 / 文档 / 会议记录，要求总结
- 需要从材料里抽出行动项

## 步骤

1. 判断材料类型：决策 / 说明 / 研究 / 纪要
2. **结论**：3 条以内，每条一句话
3. **依据**：支撑结论的关键事实，标出原文位置（章节 / 页码 / 时间戳）
4. **待办**：谁、做什么、何时；材料没写的标「未指定」
5. **风险 / 未决**：明确冲突、缺口、需要确认的点

## 规则

- 结论必须有原文依据，不补充材料里没有的判断
- 数字、日期、专有名词保持原样
- 材料互相矛盾时并列写出，不替它下结论
- 篇幅控制在原文的 10% 以内

## 禁止

- 把「可能 / 也许」写成确定结论
- 漏掉否定句和限制条件
- 编造负责人和截止时间
