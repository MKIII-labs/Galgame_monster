Computer Bridge

让本机的 AI 在受控标签页上执行操作。扩展只连接 127.0.0.1，不访问外网。

连接码

在应用里打开：设置 → Agent → Computer Use → 「复制连接码」，粘贴到这里。

怎么用

  1. 在应用里把「浏览器后端」切到「扩展（复用登录态）」。
  2. 这里填好连接码并保存。扩展会自动开始轮询。
  3. 让 AI 打开一个网页：它会**新建一个标签页**并接管，不会动你正在看的页面。
  4. 第一次附加调试器时，浏览器顶部会出现「正在调试此浏览器」的提示条，这是扩展在转发命令。

注意：扩展模式复用你当前浏览器的登录态，因此只能操作应用里已授权的站点； 银行 / 支付 / 邮箱 / 密码管理器仍被应用侧硬拦截。
