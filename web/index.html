深度思考：开关与档位有什么区别

开关（输入框左下「✦ 深度思考」）：开启后模型在给答案前先输出一段思维链（CoT），回答通常更准，但更慢、更费 token。思维链会以可折叠的「已深度思考」块展示。

档位（低 / 中 / 高 / 最高）：控制"想多久"。本程序按当前「思考参数模式」把它作为 reasoning_effort 发送。DeepSeek 官方会对档位做映射（依其官方文档）：

本程序档位发送值DeepSeek 实际生效
低lowlow
中mediumhigh
高highhigh
最高maxmax

注意：在 DeepSeek 上「中」与「高」效果相同（都映射为 high），真正有区别的是「低 / 高 / 最高」。其它厂商对 reasoning_effort 的支持与映射可能不同，甚至不支持（会被忽略或报错）。

另：思考模式下 DeepSeek 会忽略 temperature / top_p 等采样参数（不报错但不生效）。

思考参数模式（设置 → 聊天 API）

决定"深度思考"开关如何传给接口，避免不支持的接口报错：

  • 自动：按接口地址是否含 deepseek 自动判断。
  • 不发送：完全不带思考参数，最通用。
  • OpenAI 兼容：开启时发 reasoning_effort，关闭时不发（无法表达"禁用"）。
  • DeepSeek：开启→ thinking.type=enabled，关闭→ disabled；档位走 reasoning_effort。
对话上限（输入框上方的进度条）

估算当前会话离模型上下文上限还有多远，避免"聊到一半突然报错"。

  • 单位换算（按本项目的估算口径）：1 个汉字 / 中文标点 ≈ 0.6 token，1 个英文字符 ≈ 0.3 token。即 1000 token ≈ 1700 汉字；128000 token ≈ 21 万汉字；1000000 token ≈ 170 万汉字。填写时只写数字：128K 写 128000，1M 写 1000000。
  • 已用 ≈ 本地估算 × 校准系数；校准系数取最近一次接口返回的真实 prompt_tokens ÷ 当时估算。
  • 剩余 = 上限 − 已用；剩余低于上限 10% / 5% 时进度条转黄 / 红并弹出提醒。
  • 自动压缩：达到上限时（「已用 + 为回复预留」超过上限），AI 会自动压缩你的对话历史记录——把较早的对话总结成摘要（不是删除），保留最近 8 条原文，之后照常发送。
  • 手动压缩：点进度条右侧的「压缩历史」可立即压缩一次；压缩点之后的消息不足 9 条、或未配聊天密钥时会给出提示。
  • 上限 / 预留可在「聊天 API」里按所用模型填写（默认 128000 / 4096）。估算为近似值，仅供参考。
联网搜索

输入框的「🔍 联网搜索」开关开启后：改写检索式 → 并行搜索 → 抓取正文 → 注入提示 → 再让模型回答；回答上方会出现可折叠的「参考来源」列表。后端可选博查 / Tavily 两个服务商；在「联网搜索」设置里可配置密钥、结果条数，以及是否开启「查询改写」（更准）与「抓取正文」（更全）。

用户画像：手动偏好 vs AI 自主记录
  • 手动偏好：你自己写的规则（如"回答数学题先给结论"），每轮都会注入，优先级最高。
  • 自动学习：AI 在主对话里直接读写记忆——需要记录时会自己动手，它输出的写入指令用户看不到；写入后回复下方会出现「已更新记忆」标记，点「撤销」即可回滚。判断准则来自「学习指令预设」，可自定义。
  • 写什么、改什么：由 AI 自主判断——明确要求「记住 / 删掉那条 / 改一下」会直接执行；新旧信息矛盾时以更晚、更明确者为准，不会让两条矛盾条目并存。
知识库与记忆（侧栏 🧠 知识库）
  • 本会话记忆：只属于当前对话，切到别的对话就看不到。
  • 通用知识库：可有多个、跨对话共享；在编辑器右侧勾选哪些库给"本会话"用（可多选）。
  • 用户画像库：系统库（AI 自主写入），每轮固定注入，不允许删除 / 改名。
  • AI 可否修改：分两级——会话级「允许 AI 写本会话记忆」与库级「允许 AI 修改本库」；被锁定的节点 AI 不会改。
  • 检索方式：先按关键词从记忆 / 知识库预筛候选；候选超过 20 条时才让模型挑选相关条目，最后把选中条目注入提示。
  • 图谱编辑：拖拽移动、双击空白新增、「＋ 节点」新增、点节点改内容、连线 / 删边（画布左上角工具栏）、删除节点。
图谱关系类型（箭头代表什么）

知识库的边是有向的：箭头从 A 指向 B，读作「A 关系 B」。 关系取自下面的固定词表，图上按类型着色；AI 也只能从词表里选（写别的说法会自动归一到最近的类型）。

    你可以点节点后用「＋ 连线」手动建立关系；AI 整理记忆时若发现两个已有条目之间存在明确关系，也会主动连边。

    图像识别：独立视觉 API vs 聊天模型
    • 默认用「图像 API」里配置的视觉模型。
    • 开启「使用聊天模型识别图片」后，改由「聊天 API」的模型与密钥识图（要求聊天模型自带视觉能力，如 GPT-4o / deepseek-flash / 通义兼容模式）。
    • 两种视觉协议的区别：
      · DashScope 原生：图片放 input.messages[].content 的 {"image": ...}，结果取 output.choices[0].message.content。
      · OpenAI 兼容：图片放 messages[].content 的 {"type":"image_url"}，结果取 choices[0].message.content。
    账户余额

    在「聊天 API / 图像 API」面板查看余额，打开设置时自动查一次，也可点「刷新」。

    • DeepSeek：按接口地址自动识别，调用官方 GET /user/balance。
    • 其它厂商：若提供余额接口，在「余额查询地址」填写（GET + Bearer）；留空且非 DeepSeek 则显示"不支持"。
    用量统计（侧栏 📊 用量统计）

    每次回复下方会显示本次消耗的 token；「用量统计」里可按近 7 天 / 近 30 天 / 近 12 个月查看按模型与按日 / 月的明细，并用折线图展示趋势。

    消息操作（悬停消息时显示）
    • 复制：复制消息文本。
    • 撤回（用户消息）：连同它后面的 AI 回复一起移除。
    • 修改（用户消息）：行内编辑后重新发送，其后的回复会被丢弃并重新生成。
    • 重新发言（AI 回复）：丢弃这条回复及之后的消息，重新生成。
    • 选择文本（AI 回复）：切换成源码视图，这样复制到的是 Markdown / LaTeX 源码（而非渲染后的文字 / 公式）。
