沉浸

剧本

语音输入

台词朗读（TTS）

模型接入

图像识别：独立视觉 API vs 聊天模型
  • 默认用「视觉模型」里配置的视觉 API。
  • 开启「使用聊天模型识别图片」后，改由「聊天模型」的模型与密钥识图（要求聊天模型自带视觉能力，如 GPT-4o / deepseek-flash / 通义兼容模式）。
  • 两种视觉协议的区别：
    · DashScope 原生：图片放 input.messages[].content 的 {"image": ...}，结果取 output.choices[0].message.content（qwen-vl-plus / max）。
    · OpenAI 兼容：图片放 messages[].content 的 {"type":"image_url"}，结果取 choices[0].message.content（GPT-4o、vLLM / Ollama、deepseek-flash）。
账户余额

在「聊天模型 / 视觉模型」面板查看余额，打开设置时自动查一次，也可点「刷新」。

  • DeepSeek：按接口地址自动识别，调用官方 GET /user/balance。
  • 其它厂商：若提供余额接口，在「余额查询地址」填写（GET + Bearer）；留空且非 DeepSeek 则显示"不支持"。

对话行为

深度思考：开关、档位与参数模式

开关（输入框左下「✦ 深度思考」）：开启后模型在给答案前先输出一段思维链（CoT），回答通常更准，但更慢、更费 token。思维链会以可折叠的「已深度思考」块展示。

档位（低 / 中 / 高 / 最高）：控制"想多久"。本程序按「思考参数模式」把它作为 reasoning_effort 发送。DeepSeek 官方会对档位做映射（依其官方文档）：

本程序档位发送值DeepSeek 实际生效
低lowlow
中mediumhigh
高highhigh
最高maxmax

参数模式（设置 →「深度思考」）决定上述开关如何传给接口，避免不支持的接口报错：

  • 自动：按接口地址是否含 deepseek 自动判断。
  • 不发送：完全不带思考参数，最通用。
  • OpenAI 兼容：开启时发 reasoning_effort，关闭时不发（无法表达"禁用"）。
  • DeepSeek：开启→ thinking.type=enabled，关闭→ disabled；档位走 reasoning_effort。

注意：在 DeepSeek 上「中」与「高」效果相同（都映射为 high），真正有区别的是「低 / 高 / 最高」。其它厂商对 reasoning_effort 的支持与映射可能不同，甚至不支持（会被忽略或报错）。

另：思考模式下 DeepSeek 会忽略 temperature / top_p 等采样参数（不报错但不生效）。

上下文上限（输入框上方的进度条）

估算当前会话离模型上下文上限还有多远，避免"聊到一半突然报错"。相关设置项在「上下文与压缩」。

  • 单位换算（按本项目的估算口径）：1 个汉字 / 中文标点 ≈ 0.6 token，1 个英文字符 ≈ 0.3 token。即 1000 token ≈ 1700 汉字；128000 token ≈ 21 万汉字；1000000 token ≈ 170 万汉字。填写时只写数字：128K 写 128000，1M 写 1000000。
  • 已用 ≈ 本地估算 × 校准系数；校准系数取最近一次接口返回的真实 prompt_tokens ÷ 当时估算。
  • 剩余 = 上限 − 已用；剩余低于上限 10% / 5% 时进度条转黄 / 红并弹出提醒。
  • 自动压缩：达到上限时（「已用 + 为回复预留」超过上限），AI 会自动压缩你的对话历史记录——把较早的对话总结成摘要（不是删除），保留最近 8 条原文，之后照常发送。
  • 手动压缩：点进度条右侧的「压缩历史」可立即压缩一次；压缩点之后的消息不足 9 条、或未配聊天密钥时会给出提示。
  • 上限 / 预留可在「上下文与压缩」里按所用模型填写（默认 128000 / 4096）。估算为近似值，仅供参考。
联网搜索（改写 / 抓取 / 来源）

输入框的「🔍 联网搜索」开关开启后：改写检索式 → 并行搜索 → 抓取正文 → 注入提示 → 再让模型回答；回答上方会出现可折叠的「参考来源」列表。

  • 服务商 / 密钥：在「联网搜索」设置里选服务商（内置博查 / Tavily）并填密钥；接口地址留空则用该服务商的默认地址。
  • 查询改写：用「聊天模型」把你的问题转成 2–3 个关键词式检索式，口语化长问句的召回明显更好；未配聊天密钥时自动回落用原问题。
  • 抓取正文：对命中的网页取正文（而不是只有摘要），信息密度更高；可设抓取条数。抓取优先走 Jina Reader（免密钥），失败回落直连抓取，再失败则保留摘要。
  • 结果条数：每个检索式各取多少条。
  • 注入不入库：抓到的正文只用于本轮提示，不会写进会话文件。

记忆与学习

用户画像：手动偏好 vs AI 自主记录
  • 手动偏好：你自己写的规则（如"回答数学题先给结论"），每轮都会注入，优先级最高。在「用户画像」里编辑。
  • 自动学习：打开「允许 AI 记录用户画像」后，AI 在主对话里直接读写记忆——需要记录时会自己动手，它输出的写入指令用户看不到；写入后回复下方会出现「已更新记忆」标记，点「撤销」即可回滚。判断准则来自「学习指令预设」，可自定义。
  • 写什么、改什么：由 AI 自主判断——明确要求「记住 / 删掉那条 / 改一下」会直接执行；新旧信息矛盾时以更晚、更明确者为准，不会让两条矛盾条目并存。
  • 查看与编辑：点「🧠 打开用户画像知识库」可跳到知识图谱里查看 / 修改每条偏好。
学习指令（预设与自定义）

决定 AI 在对话中如何判断「该记什么、改什么、删什么」，以及写入用户画像时的准则。

  • 预设下拉有三类来源：内置默认、你保存的预设、当前未保存的自定义内容（切走前会提示）。
  • 自定义指令：留空即用内置默认。支持三个占位符：{current_auto}（当前已记录的画像）、{user_input}（用户这句话）、{ai_reply}（AI 的回复）。
  • 另存为 / 删除预设可把当前内容存成命名预设，随时切换。
知识库与记忆（侧栏 🧠 知识库）
  • 本会话记忆：只属于当前对话，切到别的对话就看不到。
  • 通用知识库：可有多个、跨对话共享；在编辑器右侧勾选哪些库给"本会话"用（可多选）。
  • 用户画像库：系统库（AI 自主写入），每轮固定注入，不允许删除 / 改名。
  • AI 可否修改：分两级——会话级「允许 AI 写本会话记忆」与库级「允许 AI 修改本库」；被锁定的节点 AI 不会改。
  • 检索方式：先按关键词从记忆 / 知识库预筛候选；候选超过 20 条时才让模型挑选相关条目，最后把选中条目注入提示。
  • 图谱编辑：拖拽移动、双击空白新增、「＋ 节点」新增、点节点改内容、连线 / 删边（画布左上角工具栏）、删除节点；节点可调大小与颜色（AI 也能设，用于区分重要度 / 分组）。
  • 图谱力学：右侧「⚙ 图谱设置」可调斥力 / 中心引力 / 弹簧强度 / 线段长度，拖动即时生效，设置随该知识库保存。
图谱关系类型（箭头代表什么）

知识库的边分单向和双向两种： 单向箭头从 A 指向 B，读作「A 关系 B」（如因果、条件这类有先后的）； 双向两端都有箭头，表示互相（如相关、同义、对立这类 symmetric 关系默认画双向）。 关系取自下面的固定词表（标注「⇄ 默认双向」的即为对称关系），图上按类型着色；AI 也只能从词表里选（写别的说法会自动归一到最近的类型）。

    你可以点节点后用「＋ 连线」手动建立关系，并在表单里选择「单向 →」或「双向 ⇄」；AI 整理记忆时若发现两个已有条目之间存在明确关系，也会主动连边（方向按关系类型自动判断，也可由 AI 显式指定）。

    外观与演出

    主题与外观（浅色 / 深色 / GAL 主题）
    • 界面主题（设置 →「主题与外观」）：浅色 / 深色，切换后界面与应用窗口标题栏一起变。
    • GAL 演出主题（设置 →「GAL 演出」）：樱粉 / 夜蓝 / 和风纸三套，决定对白框、名字牌与选项的观感。
    • 覆盖关系：进入 GAL 模式时，GAL 主题会覆盖到全部 UI（含设置弹窗、提示、弹窗等）；退出 GAL 模式即恢复界面主题。
    GAL 演出：主题 / 打字机 / 特效 / 立绘
    • 演出主题：三套配色（樱粉 / 夜蓝 / 和风纸），作用于对白框、说话人名牌与选项按钮。
    • 对白框最大高度：占舞台高度的百分比（30–70）；对白框是浮在立绘之上的半透明层，立绘会自动避让。
    • 打字机：「逐字显示对白」开关 + 速度（8–120 字/秒，线性生效）。关闭即整句直接出现。
    • 关键词特效：在台词里写 *关键词* 或 【关键词】 触发（不会被朗读）。可自定义关键词、CSS 效果与音效——编辑 data/gal/effects/effects.json，音效放 data/gal/effects/；mode 支持 before / after / loop / stop（loop、stop 用于循环音效）。
    • 立绘过渡：换人或进出场时的淡入淡出动画；工具条还可设为「沉浸式淡出」（鼠标移入才实显）。
    GAL 推进与自动写剧本
    • 对白展示：「逐段追加（可回看）」会把一轮话累积显示；「单行推进」一次只显示一句，点一下出下一句。
    • 自动播放：单行推进时，语音播完自动切下一句（快捷键 A）；「每句最短展示」控制切换的最短间隔。
    • AI 自动写剧本：打开后由 AI 依据「角色设定 + 用户画像」先写一份分幕大纲，再逐幕展开推进剧情，最后一幕自动收束为结局。
    • 总幕数 / 每幕轮数：控制大纲的规模与每幕的对话长度。
    • 剧本按会话独立保存；可在 GAL 工具条 ⋯ → 🎬 剧本 查看大纲或重新生成。
    语音输入（实时转写 + AI 矫正）
    • 实时转写：点「🎤 语音输入」后边说边出字，文字实时进入输入框；再点一下停止。识别在本机完成（sherpa-onnx 流式模型），音频不出电脑。
    • 两遍识别（更准）：说话时用流式模型出字；停止后再用离线模型（SenseVoice）对整段音频重新解码，用更准的结果覆盖实时文本。需先运行 scripts/fetch_speech_model.py final 下载精修模型；未下载时自动沿用流式结果。
    • 降噪（默认关闭）：点「🎛 降噪」开启后，会先在本机对音频做流式去背景噪声（DPDFNet）再识别，嘈杂环境下更准；安静环境可关掉。需先运行 scripts/fetch_speech_model.py denoise 下载降噪模型。
    • AI 矫正（默认关闭）：在「设置 → 语音与朗读」里打开后，停止时会用「聊天模型」的模型对文本做最小必要校对（补标点 / 纠错别字 / 去口癖）。
    • 可改可撤回：矫正后的文本可以直接编辑；输入框下方的「撤回原文」按钮可一键恢复未矫正的原始转写。
    • 发送键保护：录音中、识别中、AI 矫正中发送键都会置灰不可点（Enter 也不会发送），避免"发出去的"与"随后矫正的"两段文本同时留存。
    • 模型：需先运行 scripts/fetch_speech_model.py streaming 下载流式中文模型；缺失时点麦克风会有提示。
    台词朗读（TTS）：三种后端与音色克隆
    • 三种后端：Edge TTS（免费、免密钥，推荐）/ OpenAI 兼容 /v1/audio/speech / 本地 GPT-SoVITS。
    • 切句播放：GAL 模式的台词按标点切句后逐句合成播放；若该立绘配了「绑定音频」，默认优先播放它（可在角色设置里调优先级）。
    • 音色：可直接填音色名（如 zh-CN-XiaoxiaoNeural / alloy），也可点「查看 Edge 中文音色」列出可选值。每个角色还能存多套「配音预设」，在 GAL 工具条一键切换。
    • 测试朗读：点「🔊 测试朗读」用当前填写的配置合成一句试听。
    • 音色克隆：GAL 工具条 ⋯ → 🎙 快速克隆，给一段 5–10 秒参考音频 + 参考文本即可克隆（GPT-SoVITS 零样本）；带微调权重的角色会在合成前自动切换加载。需本机跑一个 GPT-SoVITS 服务。

    编辑器与 Agent

    IDE / Solo 模式（VS Code 风格工作区）
    • 切换：左侧栏顶部「Solo | IDE」切换；状态会保存，下次打开还记得。
    • Solo：以对话为主。
    • IDE：VS Code 风格布局 —— 最左活动栏（资源管理器 / 搜索 / 在 VS Code 打开）、侧边栏文件树、中间多标签编辑器、底部状态栏（路径 / 编码 / 行列 / 语言），右侧仍是窄栏对话。工作区根目录 = 当前会话的沙箱，切会话会自动换。
    • 编辑器：内置 Monaco（VS Code 同款，本地内置、离线可用）——语法高亮、多光标、查找替换、MiniMap、代码折叠。
    • 快捷键：Ctrl+S 保存、Ctrl+P 快速打开文件、Ctrl+Shift+P 命令面板；完整清单见左侧「快捷键」。
    • 文件操作：新建文件 / 新建文件夹 / 重命名 / 删除；可同时开多个标签，未保存的标签带 ● 标记。
    • 搜索：点活动栏放大镜，在沙箱内按内容或文件名搜索。
    • 编码：读取自动识别 UTF-8 / GBK，保存时按原编码写回，中文文件不乱码。
    • AI 改动同步：AI 每次写/改/删/移动文件后，目录树自动刷新，并把改过的文件高亮；若改的正是你打开的文件且你没在编辑，会自动重载。
    • 与 VS Code 联动：点活动栏「🧩」可在本机 VS Code 中打开当前沙箱（用你自己的 VS Code 和它的全部插件）；命令面板里的「从 VS Code 导入设置与扩展清单」会只读读取你的 VS Code 设置（字号 / 缩进 / 换行 / 空白字符 / 滚轮缩放）并应用到编辑器，同时列出你已装的扩展（仅展示，不安装）。
    • 安全：与 Agent 同一套沙箱约束——越界、.git / .venv / node_modules / __pycache__ 与 data/ 都不会出现在工作区里。
    Agent 沙箱（文件读写）与中途提问
    • 开启：点输入框上方的「🛠 Agent」开启，再点「📁」选择沙箱目录；设置按会话保存。
    • 能力：模型可在沙箱内 列目录 / 读文件 / 搜索 / 写文件 / 改文件 / 建目录 / 移动 / 删除；不提供命令行工具。
    • 安全：只接受沙箱内相对路径，越界、绝对路径直接拒绝；.git / .venv / node_modules / __pycache__ 与本项目 data/ 永久禁止访问。
    • 改动可撤回：每次写操作生成一张工具卡片，点卡片上的「撤回」即可恢复该次改动。
    • 读沙箱外：输入框的「📤 读沙箱外」开关（仅 Agent 开启时显示）可让 AI 在你明确要求时读取沙箱外的文件——只读，写入仍只在沙箱内。
    • 中途提问：需要你决策时，AI 会在对话里弹出一张提问卡（可点选项或自己输入），你回答后它会原地继续，不用重新发消息。提问与 Agent 无关，不选沙箱也能用。

    消息操作（悬停消息时显示）
    • 复制：复制消息文本。
    • 撤回（用户消息）：连同它后面的 AI 回复一起移除。
    • 修改（用户消息）：行内编辑后重新发送，其后的回复会被丢弃并重新生成。
    • 删除本条：只删这一条，不影响其它消息。
    • 重新发言（AI 回复）：丢弃这条回复及之后的消息，重新生成。
    • 选择文本（AI 回复）：切换成源码视图，这样复制到的是 Markdown / LaTeX 源码（而非渲染后的文字 / 公式）。
    改动保存后立即生效，无需重启（Ctrl+S 保存、Esc 关闭）。
