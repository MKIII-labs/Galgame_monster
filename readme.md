## 🎯 这是什么

**一个装在自己电脑上的 AI 工作台。** 聊天、记忆、读写文件、排日程、Galgame 式演出，都在本机跑；模型走你自己的 API Key（任意 OpenAI 兼容接口），会话、画像、笔记、上传的图片全部落在本地 `data/` 目录，不上传第三方。

**和网页版 AI 的区别**：它能持续记住你（画像 + 知识库 + 图状记忆），能真的动你电脑上的文件（有沙箱边界），能到点弹 Windows 通知，还能按你定的剧情和角色演出来。

**适合谁**：手里有模型 API Key、希望数据留在本机、且愿意自己改提示词 / 加工具 / 换角色的人。提示词是 `resources/prompts/` 下的 `.md`，角色是 `data/gal/characters/` 下的目录，都能直接改。

### ⚡ 30 秒跑起来

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

首次启动会自动弹出设置，填「聊天模型 → API 密钥」就能开始用。语音输入、GAL 配音、图寻游戏都是可选功能，不配也不影响聊天。

> 需要 **Python 3.10+**、Windows（系统通知走 Windows 计划任务）。三行必须用同一个 `.venv` 解释器——装到全局再启动会缺库。完整步骤见下方[快速开始](#-快速开始)。

## 📖 项目简介

**Galgame_monster** 是一个本地运行的图形化 AI 交互平台。界面用 Web 技术（HTML/CSS/JS）渲染，由 Python 提供本地后端，并以「应用模式窗口」打开——没有地址栏与标签页，观感与独立桌面程序一致。

核心设计理念：**让 AI 主动适应用户，而不是让用户反复调教 AI**。

界面分四种主模式：**Solo**（以对话为主）、**IDE**（VS Code 风格工作区）、**大厅**（AI 互动玩法：图寻游戏、数学竞技场、模拟股市、**GAL 剧场**、模拟面试）、**工作台**（个人日程、任务拆解执行与产物归档；写操作默认要你确认一次）。GAL 已从顶部模式移入大厅，作为独立的「GAL 剧场」入口。
它不只是"你问我答"：**定时提醒**（到点在 Windows 弹通知，程序关着也弹）和 **AI 主动发消息**（按间隔自己找你说话）让它更像一个常驻的终端助手。

### 交互体验
| 功能 | 说明 |
|------|------|
| **流式输出** | 回复逐字显示，可随时点「停止」中断（**联网搜索阶段也能立即停**），已收到的内容会保留；被中断的回复可点「**继续输出**」从断点接着写完——写回**同一条消息**，刷新页面后按钮仍在 |
| **Markdown 渲染** | 标题、粗体、列表、引用、表格、分割线 |
| **代码块** | 语法高亮 + 语言标签 + 一键复制 |
| **LaTeX 公式** | 数学公式用 KaTeX 实时排版 |
| **多会话管理** | 左侧会话栏：新建 / 切换 / 双击重命名 / **删除（有二次确认，并提示连同存档一起清掉、不可恢复）**，各自独立历史 |
| **分支存档 / 倒带** | 每轮结束**自动留档**（也可手动打点并命名），面板里可从任意存档点 **回退**（覆盖当前会话）或 **分支**（复制出一条新会话线，**原线完整保留**）；存档一并还原 **对白 / 立绘 / 背景 / BGM / 舞台状态参数 / 剧情节点 / 会话记忆**；每会话最多 60 个存档点，删会话时连带清理。**存档不含上传的图片附件文件** |
| **消息操作** | 用户消息可「撤回」（连同后续回复移除）或「修改」后重发；AI 回复可「重新发言」；「选择文本」切换源码视图，便于复制 Markdown / LaTeX 源码 |
| **输入框增强** | 实时字符数提示 · **清空按钮** · **`/` 指令菜单**（`/clear` `/new` `/compress` `/kb` `/settings` `/theme`，以及 AI 类 `/polish` `/shorten` `/expand` `/translate`）· **`@` 引用**本会话记忆条目 · **历史补全**（输入即匹配发过的内容，`↑↓` 选择、`Tab` 采纳）· 空框按 `↑` 调出上一条 · `Ctrl/⌘+Enter` 也能发送 · `Esc` 清空 · 粘贴超长文本提示 · **AI 优化输入**（工具栏 ✨ 按钮或 `Ctrl/⌘+I`：润色 / 精简 / 扩写，结果可一键撤销，并显示识别出的意图）。以上补全与菜单均为**本地即时**响应，不消耗 token |
| **图片 / 文档附件** | 输入框右侧**回形针按钮**弹出菜单（上传图片 / 上传文档）；也可 **`Ctrl+V` 粘贴**或**拖入窗口**（非图片文件自动走文档通道）。文档支持 txt / md / csv / json / docx / xlsx / **pdf**，发送时自动抽取正文。**PDF 有文本层直接读；扫描件或中文 CID 乱码会自动逐页渲染、交给视觉模型逐字识别**（聊天模型有视觉则优先用它，否则用「视觉模型」）。发送后图片在聊天记录里显示缩略图，点击放大 |
| **联网搜索** | 输入框里的「联网搜索」开关。AI 会**先判断这个问题要不要联网**（闲聊、写代码、数学之类跳过，不浪费额度）；**过程完全可见**：正在判断 → 生成了哪几个检索式 → 命中多少条 → 正在读取第几篇网页（含抓取失败提示）；完成后列出**可点开的参考来源**，回答里用 `[1] [2]` 标注。检索与读网页阶段可随时「停止」。服务商支持**博查 / 豆包搜索（火山）/ Tavily**，可自填地址与密钥；「重新发言 / 继续输出」会**复用已有来源**，不重复联网 |
| **语音输入** | 输入框**右侧的麦克风按钮**：点一下**边说边出字**（本机流式识别，音频不出电脑）；停止后用离线模型（SenseVoice）**两遍精修**，最终文本更准；结束后可选 **AI 矫正**（补标点/纠错别字/去口癖），可一键「撤回原文」。**降噪**（本机 DPDFNet 流式去背景噪声）在「设置 → 语音与朗读」里开启 |
| **定时提醒** | 直接说「明天 9 点提醒我交作业」，AI 会自己登记；也可在「设置 → 提醒与主动」手动添加（时间 / 内容 / 一次性·每天·每周）。**到点弹 Windows 系统通知**（程序已关闭也会弹，走系统计划任务），同时在会话里留一条消息；任务列表可随时删除 |
| **AI 主动发消息** | 在「设置 → 提醒与主动」为某个会话开启后，AI 会**按间隔主动找你说话**（默认 40–120 分钟随机，可改）。**开启后约 20 秒先发一条**给即时反馈，之后才按节奏来；你刚说过话会先让路，连续 2 次没得到回应会自动暂停。面板里能看到每个会话的下次时间，也有「立即发一条试试」。GAL 模式下会作为对白插入舞台 |
| **多套主题** | 三套**互相独立**的配色，各存各的配置：**界面主题**（6 套：浅色 / 深色 / 高对比暗 / 暗夜紫 / 深林绿 / 护眼纸白，一键切换立即生效，**应用窗口标题栏跟随主题**）、**IDE 主题**（8 种：**跟随 VS Code**（读本机 `settings.json` 的 `workbench.colorTheme`，约 5s 内跟随）/ **VSCode Dark Modern** / **Light Modern**（VS Code 现在的出厂默认）/ VSCode Dark+ / Light+（更早的「传统」默认）/ Trae Dark / Light / Deep Blue；与界面主题**完全解耦**，只在 IDE 模式覆盖整个 IDE 界面，退出即还原）、**GAL 演出主题**（6 套：樱粉 / 夜蓝 / 和风纸 / 极简黑白 / 霓虹夜景 / **像素复古**，进入 GAL 后覆盖全局配色）。三套在设置里都是**带迷你预览的卡片**选择器。IDE 工作区另按 VS Code 官方参数对齐（字体栈 / 状态栏 22px·12px / 标签左内边距 12px / 命令面板 600px·圆角 6px / 部件直角 / 滚动条 14px / 交互 100ms），**文件名的取色也按 VS Code 语义**（资源管理器文件名走 `sideBar.foreground`、当前打开的文件走 `list.activeSelectionBackground` + `list.activeSelectionForeground`、标签页走 `tab.active/InactiveForeground`，都不再用强调色），逐项取值与取证来源见本地文档 `docs/IDE_VSCODE_PARITY.md`（不随仓库发布） |
| **Solo / IDE 模式** | 左侧栏顶部切换（**GAL** 与 **大厅** 见各自小节）：**Solo**＝以对话为主；**IDE**＝ **VS Code 风格**工作区（活动栏 / 文件树 / 多标签编辑器 / 状态栏），内置 **Monaco**（离线可用），`Ctrl+S` 保存、`Ctrl+P` 快速打开、`Ctrl+Shift+P` 命令面板，支持沙箱内搜索与 UTF-8/GBK 自动识别。**文件管理区可收起**：点活动栏里当前已激活的图标收起 / 展开（<code>Ctrl+B</code> 同效，可改键），状态会被记住，收起后编辑区自动占满。右侧聊天栏**可拖拽分隔条调整宽度**（双击还原，宽度会被记住）。**可一键在本机 VS Code 中打开当前沙箱**，并能只读导入 VS Code 的设置与扩展清单。编辑器支持**空白字符可视化**（关闭 / 仅选区内 / 仅行尾 / 词之间 / **全部（默认）**）：空格渲染为浅灰中点 `·`、制表符为 `→`，颜色沿用 VS Code 标准值，与主题无关 |

### GAL 演出模式

> 入口：**大厅 → GAL 剧场**。剧场使用独立会话（`gal_scope=gal`），默认不读 Solo / IDE 的历史、画像、知识库与全局规则；进入前可逐项打开（**只读**，写入始终只进本场记忆）。

| 功能 | 说明 |
|------|------|
| **舞台演出** | 背景 + 立绘 + 对白框 + 选项的 Galgame 式界面，演出主题作用于**全部 UI**（含弹窗与提示）；舞台背景图**铺满到输入区**；立绘自动靠边排位（单张 / 多张自动分栏），**不说话的自动变暗**，安全剧情可用 `cast: []` 让立绘**全部撤下**；对话框与选项**一律半透明磨砂（统一 70%，不随主题切换变化）**，对话框有**四角装饰角标**与**可点击的推进 ▼**（打字中变成「补全」），说话人**名牌骑在对话框上边框外侧**（传统日式 AVG 排版） |
| **逐段对白** | AI 把一轮话拆成若干短段，**边生成边逐段显示**（打字机 + 逐段朗读）；逐字速度可调（8–120 字/秒，全程线性生效，见 Q11）；可切「逐段追加（可回看）」或「单行推进（点一下下一句）」；输出时对白框**自动贴底** |
| **旁白与场景** | 支持 `NARR` 旁白段（不朗读）；AI 每轮会先交代场景，进入新一幕时也会把该幕的场景描述作为旁白推进对话框 |
| **推进与快捷键** | 空格 / 回车 / 点击舞台推进（打字中先补全）· **对话框右下角的 `▼` 也可直接点**（打字中会变成「点击补全」）· 按住 `Ctrl` 快进 · `A` 自动播放（**每句播完停 1.5 秒**）· **出现选项时，`↑`/`↓` 与 `Enter`/空格改判给选项**（选完才继续，此时 `↑` 不再打开回顾）· **数字键 `1`–`9` 直接选对应选项**（选项上就标着序号）· `↑` 打开回顾 · `Esc` 逐层关面板 · 右下角**实时快捷键提示**（默认折叠成小图标，随模式与状态变化）· 按 `?` 或 `Ctrl+/` 打开**完整快捷键清单**，可**逐项改键**、冲突自动拦截、一键恢复默认 |
| **选项** | AI 每轮可给 2–4 个选项，**等本轮最后一段对白完全显示完才出现**；**浮在画面中部居中**（传统日式 galgame 的做法，不再把对白框顶起来）；鼠标点选、`↑`/`↓` 移动后 `Enter` 确认、或直接按数字键 `1`–`9`；悬停与键盘选中都是「实色底 + 白字」，未选为「半透明底 + 彩字」；选定后整体淡出并随即发送。想自由发言直接用底部输入框 |
| **主动发言提示** | 本轮若**没有给选项**，AI 会按**当前场景 / 角色口吻**在最后一段末尾写一句邀请（如「（对方把杯子往前推了推，等着你开口）」），点它可直接聚焦输入框；模型没写时用一句极克制的旁白兜底。有选项时不会出现（选项本身就是邀请）。可在「设置 → GAL 演出 → 选项」关掉 |
| **输入框沉浸化** | GAL 下输入框与对白框**同字体、同圆角、同磨砂**（随演出主题变，像素主题连占位符都变成 `> _`），工具条默认收起成 `⋯`；**你打的字会实时以「你：…」+ 闪烁光标出现在对白区**，发送时对白框轻微「吸入」表示收到，聚焦输入时立绘会极轻微凑近。Solo / IDE 模式完全不受影响 |
| **首次引导** | **第一次进入 GAL** 时，右上角会浮出一个气泡（小三角指向工具条「⋯」），告诉你两条路：点「**⋯ → 剧本**」让 AI 生成大纲、按剧本一路演下去，或者什么都不设直接和角色说话。点「知道了」后就不再出现 |
| **角色与素材** | 角色即目录（`data/gal/characters/<id>/`）：人设 / 立绘（可绑情绪标签与台词音频）/ 主题色 / 剧本 / 配音预设；支持 `.char`(zip) 导入导出，并**兼容 Shinsekai 的 `character.yaml`**；角色卡片右上角有 **✎ 编辑**按钮（点卡片本身 = 切换为该角色），底部「编辑」按钮改当前角色；随项目附带一个示例剧本，首次启动自动播种 |
| **台词朗读（TTS）** | 三种后端：**Edge TTS**（免费免密钥）/ OpenAI 兼容 `/v1/audio/speech` / **本地 GPT-SoVITS**；每个角色可存多套音色预设，工具条一键切换 |
| **音色克隆** | `⋯ → 快速克隆`：给一段 5–10 秒参考音频 + 参考文本即可克隆音色（GPT-SoVITS 零样本）；有微调权重（`.ckpt` / `.pth`）的角色会在合成前自动切换加载 |
| **AI 自动写剧本** | 开启后由 AI 依据「角色设定 + 世界观 + 用户画像」编写**分幕大纲**，再**逐幕展开**推进剧情，最后一幕自动收束为结局 |
| **关键词特效** | 台词里写 `*闪光*` / `*震动*` / `*黑屏*` / `*淡入*`（或 `【…】`）触发 CSS 动画与音效，**覆盖舞台与输入区**；词表与音效可自定义（`data/gal/effects/`） |
| **舞台状态栏** | AI 依角色设定**自建临时数据**（好感度 / 生命力 / 危险度 / 时间 / 地点 / 物资…），以进度条 + 标签显示在舞台**左侧**；随剧情增减，可一键**隐藏 / 重置**；**撤回消息时数值一并回滚** |
| **舞台背景** | 背景库（`data/gal/backgrounds/`）：可上传、打分类标签（场景 / 时间 / 天气 / 氛围）；AI 按**名称或标签**自动切换舞台背景 |
| **角色介绍** | 每个角色可写一段「开场介绍」：选中角色时弹**开场卡**，会话还没有对白时作为舞台**序章**展示（支持 Markdown 排版） |
| **随机判定（骰子）** | 结果不确定时 AI 可**声明掷骰**（检定 `d20+调整值 vs DC`，或自由骰如 `2d6+1`）；由系统掷出并把结果交回 AI 演出——AI **不能自行编造结果**，一轮最多一次 |
| **NPC 自动建档** | 剧情里出现可反复对话的 NPC 时，AI 会**自动在知识库中为其建立完整角色设定**（人设 / 说话方式 / 与主角关系 / 已知经历），后续保持一致 |
| **剧情档案（侦探记录本）** | `⋯ → 剧情档案`（或舞台顶部常驻「档案」按钮）：把 AI 在本会话记下来的**人物 / 势力 / 情报线索 / 地点**按类别汇总，**只显示玩家已知的内容**（排除世界观预设，不剧透）；顶部带「列表 / 关系图」两种视图，关系图用 **vis-network** 画出条目之间的连边与关系类型 |
| **舞台方位图** | AI 每轮可给出**平面俯视图**坐标（`map`），档案面板顶部按位置画出「你 / 队友 / 威胁 / 出口」等标记，并可标注两两关系（对视 / 对峙 / 相邻）；`你` 会被高亮。旧版九宫格数据会自动换算成坐标 |
| **其它** | **舞台右上角常驻「自动播放 / 回顾对话 / 档案」三个按钮**（与「⋯」抽屉分离，一键直达；`A` 与 `↑` 快捷键同效）；角色管理（卡片 / 搜索 / 删除）；可关的「沉浸式」思考与行为提示；剧本按会话独立保存 |

| **Token 用量统计** | 侧栏「用量统计」：按近 7 天 / 近 30 天 / 近 12 个月查看**账户总量**、**按 API 端点（服务商）**、**按模型 / 按来源 / 按日或月**的明细与趋势折线图，底部还有**逐次调用明细**（时间 / API / 端点 / 模型 / 来源 / 输入 / 输出 / 缓存），可定位到具体哪一次、哪个接口花掉的 token；顶部**并列显示当前账户余额**（可点刷新）。它**只统计本程序自己发起的调用**（对话 + 图像识别 + 角色设定生成 + 剧本生成 / 续幕 + 剧情节点判定），**不含账户在其他客户端的消耗**；端点按域名聚合，旧流水没有端点字段的显示为「未记录端点」 |

### 文件 Agent（沙箱）
| 功能 | 说明 |
|------|------|
| **开启与沙箱** | 点输入区上方「Agent」，在系统目录框里选一个**沙箱目录**；设置**按会话保存**，可随时更换 |
| **可用的工具** | `list_dir` / `read_file` / `search_files` / `search_code`（语义检索代码）/ `repo_map`（仓库结构图）/ `write_file` / `edit_file` / `make_dir` / `move_file` / `delete_file` / `run_command`（在沙箱内执行**单条**命令，不支持管道、重定向与后台常驻）；`read_file` 也支持 `.pdf`（只抽文本层） |
| **安全边界** | 只接受**沙箱内**的路径（相对路径推荐，沙箱内的绝对路径也接受）；越界路径直接拒绝；`.git` / `.venv` / `node_modules` / `__pycache__` 与本项目 `data/` **永久禁止访问**；如需读取沙箱外文件，可开启输入区的「读沙箱外」（**只读**、按会话保存，需你明确要求） |
| **变更审阅** | AI 改完文件后，助手回复下方会出现一张变更卡：待审查时显示**文件名 + 完整路径 + 增删行数**，底部是「**N 个文件待审查**」和「**全部撤销 / 全部保留**」；点文件名在编辑器区打开**单栏 inline diff**（绿增红删、带行号，IDE 内嵌；Solo 模式用弹窗），多个文件用 `1/N` 翻页。审阅条支持 **撤销 / 保留**，快捷键 `Ctrl+Backspace`（撤销）/ `Ctrl+Enter`（保留）。处理完后卡片变为「本轮 N 个文件的变更已处理」；点「保留」后快照销毁，不能再撤回，工具卡上的「查看变更」可随时重新打开 |
| **改动可撤回** | 每次写操作在对话里生成一张工具卡片，点「撤回」即恢复文件快照；审阅面板里也可整组撤销。快照保存在内存里（最多 20 条），重启程序后失效 |
| **中途提问** | AI 需要你决策时会弹**提问卡**（可点选项或自己输入），你回答后它**原地继续**，无需重新发消息。**一次可抛出多个问题**：卡片顶部用 `‹ n/N ›` 翻页预览，最后点「提交全部」（留空的记作「未回答」）。**与 Agent 解耦：不开启 Agent、不选沙箱也能用** |
| **编码兼容** | 读取会自动识别 UTF-8 / GBK 等编码，编辑**按原编码写回**，中文文件不乱码 |
| **IDE 工作区** | IDE 模式的骨架见上表；此处补充：文件树**以当前会话沙箱为根**，支持沙箱内搜索、AI 改动自动刷新并高亮、**图片预览**；聊天里 AI 读写过的**文件路径可直接点击**，跳到 IDE 打开该文件 |

### 功能大厅（AI 互动玩法）

侧栏模式切换的第 4 个按钮「**大厅**」：一屏卡片式入口，承载各类 **AI 可以一起玩**的互动功能。

| 功能 | 说明 |
|------|------|
| **图寻游戏** | 系统随机给出一张**真实拍摄的照片**，你和 AI 对手在世界地图上各自标出「照片是在哪拍的」；全员标完自动结算，**离真实拍摄点最近的人赢**。地图支持缩放 / 拖拽 / 点击标注，标记可拖动微调 |
| **放大看题面** | 点照片（或右上角放大镜）开**全屏大图**：滚轮以光标为锚点缩放、按住拖动平移、双击在「适应窗口 / 原始尺寸」间切换，`Esc` / 图片外轻点 / ✕ 关闭。路牌、车牌、门牌这类细节能看清了再下判断 |
| **标点上的信息** | 每个标点**正上方**直接显示该参与者名字，结算后就地变成「名字 · 距离」；真值点的标签挂在**下方**并显示拍摄地点经纬度（猜得准的标点几乎与真值重合，一上一下才不会互相压住）。标签随地图平移/缩放免费跟随，**每帧零额外计算** |
| **AI 对手** | 0–3 位可选（列表默认记忆上次选择）。三位 AI 的差异体现在**看图切入点**：植被地貌 / 建筑与文字 / 交通与市政设施。AI 用你已配置的**视觉模型**看图；未配视觉模型时退用**聊天模型**（若它支持图像）；两条都不可用则降级为区域内**盲猜**，并在名单上如实标注「盲猜」 |
| **题库来源** | 对接 **Panoramax**（开放街景图库，免密钥）。照片与**拍摄点真实经纬度**都来自该接口，项目本地不维护图片与坐标数据集。图源不可达或区域无照片时会明确报错并可一键重试 |

### 工作台（个人日程 / 任务 / 产物）

侧栏模式切换的第 5 个按钮「**工作台**」：一屏三栏，分别是**今日**、**任务**、**产物**。

| 能力 | 说明 |
|------|------|
| **个人日程** | 新建 / 删除日程，支持**每天 / 每周 / 每月**重复、地点、提前 5–60 分钟提醒；创建时自动做**时间冲突检测**并提示重叠的日程。设置页里的旧提醒会在启动时**自动并入这里**（标记「旧提醒」，程序关着也能弹的系统任务保持不变） |
| **任务拆解执行** | 可以在对话里说「帮我拆成任务并执行」，AI 用 `task.create` 生成步骤；也可以在工作台手动建。每个任务有 `待开始 / 进行中 / 已暂停 / 已完成 / 失败 / 已取消` 状态与逐步进度，支持**暂停 / 继续 / 取消**。**单轮内能做完的事直接用文件 Agent；需要跨轮、暂停、留产物的才用任务**。任务步骤还能调用**联网搜索、文档解析、笔记读写**等能力，把「查资料 → 总结 → 写笔记」串成一条链 |
| **写操作确认** | 任务里涉及写文件、建日程等**写操作**的步骤，第一次会停在「待确认」；你在任务详情里点「确认执行」才继续。避免 AI 自动改东西 |
| **断点恢复** | 任务与步骤状态实时落盘。进程重启后，原本在跑的任务统一转为「已暂停」，**不会自动重跑**，避免同一写操作执行两次 |
| **产物归档** | 任务写出的文件会登记到「产物」栏；点一下直接**在线预览**（文本 / 图片），不用离开应用 |
| **工作流** | 「触发器 → 动作」：手动 / 定时（每天或指定星期）/ 事件（任务完成、日程到点）。动作支持创建任务、发通知、建日程、**发消息到会话、本机朗读**、调用任意能力。内置「晨间简报 / 周复盘 / 收件箱整理 / 学习复盘 / 生活缴费提醒」模板，并会按当前**场景**把相关模板标为「推荐」 |
| **统一记忆** | 把画像、知识库、**笔记库**、会话记忆镜像成可检索索引，另加手动记忆与任务结果。**默认只显示手动记忆与任务结果**；勾选「包含知识库 / 画像 / 笔记」才显示镜像条目，且镜像**只读**，可点「打开来源」跳到图谱节点或对应笔记。添加记忆时可选写入**用户画像 / 本会话 / 知识库 / 仅全局**（偏好→画像，事实/事件→本会话，笔记→知识库）；知识库、笔记或会话改动后索引**自动更新**，不需要手动重建 |
| **场景包** | 通用 / 办公 / 学习 / 生活四种场景，切换后影响系统提示的「场景纪律」与能力展示顺序；场景按会话保存。**与用户画像冲突时以画像为准**，场景只做补充 |
| **对话里直接用** | 日程与任务能力也注册进了主对话：说「明天 9 点提醒我开会」「把这周安排列出来」即可，不需要先切模式 |

数据落在 `data/assistant.db`（SQLite，WAL 模式）；原来的 `sessions.json` / `config.json` **完全不迁移**。
架构、表结构、API 与扩展方式见本地开发文档 `docs/WORKSPACE_DESIGN.md`（不随仓库发布）。

## 🚀 快速开始

### 1. 安装 Python
需要 **Python 3.10 或更高版本**。`requirements.txt` 里的 `pywinpty>=3.1.0` 只支持 3.10+，用 3.8 / 3.9 会在装依赖时直接报「找不到可用版本」。未安装请访问 [python.org](https://www.python.org/) 下载安装。

### 2. 创建虚拟环境并安装依赖
```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```
> **安装和运行必须用同一个解释器。** `.venv` 不随仓库提交，但 `Galgame_monster.bat` 会优先使用 `.venv\Scripts\pythonw.exe`：如果依赖装在了全局 Python，双击 bat 后终端、语音等依赖库的功能会提示「缺少 xxx」。
> 不想用 `.venv` 也可以，那样请保证 `pip install` 和启动用的是同一个全局解释器。
> 界面依赖的 KaTeX / highlight.js 通过 CDN 加载，无需本地安装。

### 3. 下载语音识别模型（可选，仅「语音输入」需要）
语音识别在**本机离线**运行（音频不出电脑），模型落在 `data/models/`，不会提交：
```bash
python scripts/fetch_speech_model.py streaming   # 流式识别，约 126MB（必装）
python scripts/fetch_speech_model.py final       # 离线精修「两遍识别」，155MB（可选，更准）
python scripts/fetch_speech_model.py denoise     # 流式降噪，8.4MB（可选，嘈杂环境）
```
> 网络受限时先设代理：`$env:HTTPS_PROXY="http://127.0.0.1:7897"`（PowerShell）。
> 不下载也能正常使用其它功能，只是点麦克风会提示模型未就绪。

### 4. 运行
```powershell
.\.venv\Scripts\python.exe main.py
```
也可以直接双击 `Galgame_monster.bat`（会自动使用 `.venv` 里的 `pythonw`，无控制台窗口）。
启动后会自动打开应用窗口。**首次运行**会自动弹出设置，请先填写「聊天模型 → API 密钥」。
退出：关闭应用窗口即可；或在控制台按 `Ctrl+C`。

> **浏览器**：优先用 **Edge / Chrome**（程序会自动找本机的 Edge，其次 Chrome，找不到才回退到系统默认浏览器）。
> 界面用了 `color-mix()` / `dvh` / `:focus-visible` 等较新特性，**建议 Chromium 内核 111+ 或 Firefox 121+ / Safari 16.4+**；更旧的浏览器配色与窄屏适配会退化（功能仍可用）。

### 5. 建桌面快捷方式（可选，Windows）
1. 右键 `Galgame_monster.bat` → **发送到 → 桌面快捷方式**
2. 右键那个快捷方式 → **属性 → 更改图标** → 选根目录的 `app.ico`

> `.bat` 用 `%~dp0`（自身所在目录）定位，所以**项目放到哪个盘、哪个文件夹都能用**。
> 它默认用 `.venv` 里的 `pythonw.exe`（无控制台窗口）；找不到 `.venv` 时自动回落系统的 `pythonw`。

## ⚙️ 配置说明

> 各功能的实际作用与区别，可在「设置 → **功能说明**」里逐项查看（含深度思考档位的映射差异等）。

### 聊天 API（智能聊天 + 记忆读写）
填写任意 **OpenAI 兼容**接口的地址、模型名与密钥即可。例如：

| 服务 | 接口地址 | 模型名 |
|------|----------|--------|
| DeepSeek 官方 | `https://api.deepseek.com/chat/completions` | `deepseek-flash` |
| 本地 Ollama | `http://localhost:11434/v1/chat/completions` | 你拉取的模型名 |

> 只填 base URL（如 `https://api.deepseek.com`）时会自动补全为 `/v1/chat/completions`。

### 图像 API（图像识别）
- **DashScope 原生**：图片放 `input.messages[].content`，结果取 `output.choices[0].message.content`。例：阿里云百炼 `qwen-vl-plus` / `qwen-vl-max` / `qwen-vl-ocr`
- **OpenAI 兼容**：图片放 `messages[].content`（`type=image_url`），结果取 `choices[0].message.content`。例：`deepseek-flash`、GPT-4o、vLLM / Ollama 本地多模态

> 顶部有「**使用聊天模型识别图片**」开关：开启后不再用上面的视觉 API，改由「聊天 API」的模型与密钥识图（要求聊天模型自带视觉能力）。
> **功能大厅的「图寻游戏」里的 AI 对手看图也走这两条通道**，且顺序与本开关一致：开启就用聊天模型，否则先试视觉 API、
> 失败再回落聊天模型，两条都不可用才降级为盲猜。

### 联网搜索
在「设置 → 联网搜索」里选**服务商**、填 **API 密钥**（地址栏留空就用默认接口）：

| 服务商 | 价格 | 说明 |
|--------|------|------|
| **豆包搜索（火山）** | 0.02 元/次，**每月免费 500 次** | 推荐：国内直连、中文结果好。到 `console.volcengine.com/search-infinity` 开通「web搜索」并创建 API Key |
| **博查 Bocha** | 约 0.036 元/次 | 国内直连。申请：`open.bochaai.com` |
| **Tavily** | $8 / 千次，每月 1000 次免费 | 面向 AI、英文强；国内访问可能需要代理。申请：`app.tavily.com` |

- **「查询改写」开关**：开启时由聊天模型**先判断这个问题要不要联网**，需要才给出 2–3 个检索式并并行搜索（不会多花一次调用）；关闭时不再判断，直接用一个检索式搜。
- **「抓取正文」开关**：对命中的网页取正文而不只是摘要，结果更准；关掉则只用摘要，更快更省。

### 定时提醒与主动聊天
这两项由后端的一个**调度线程**驱动（每 15 秒扫一次到期任务），任务存在 `data/tasks.json`，与 `sessions.json` 分开。

**定时提醒**
- 触发方式：在对话里说「明天 9 点提醒我交作业」（AI 通过 `set_reminder` 工具自己登记）；或在「设置 → 提醒与主动」手动添加。
- **系统通知走 Windows 计划任务**：每条提醒会在系统里注册一个一次性计划任务，到点由 `scripts/notify.ps1` 弹通知——所以**本程序关闭时也照样提醒**。
- 前提是**你已登录 Windows**；程序内的会话消息则只在程序运行时出现。

**主动聊天**
- 只有**本程序在运行时**才会发生（它要调用模型生成内容），计划任务做不到。
- 间隔是「最短~最长」之间的随机值；改完**立即生效**。
- 你 3 分钟内有活动会先让路；连续 2 次主动都没得到回应会自动暂停。

### 账户余额
- **DeepSeek**：按接口地址自动识别，调用官方 `GET /user/balance`。
- **其它厂商**：若提供余额接口，在「余额查询地址」里填该地址（GET + Bearer 鉴权）；留空且非 DeepSeek 则显示「不支持」。
- 打开设置时自动查询一次，也可点「刷新」手动查询。

### 用户画像
- **手动偏好**：你主动设置的规则，优先级更高，每轮都会注入。
- **自动学习**：AI 在**主对话里直接读写**「用户画像」知识库的节点——明文说「记住 / 删掉那条 / 改一下」会直接执行，它输出的写入指令用户看不到。写入后回复下方会出现「已更新记忆」标记，点「撤销」可回滚；新旧信息矛盾时以更晚、更明确者为准，不会让矛盾条目并存。
- 可随时关闭画像写入，或自定义判断准则（支持 `{current_auto}` `{user_input}` `{ai_reply}` 占位符），详见「设置 → 功能说明」。

### 台词朗读（TTS）与音色克隆
GAL 模式的台词可自动朗读，服务商在「设置 → 语音与朗读」里选：

| 服务 | 地址 | 密钥 | 说明 |
|------|------|------|------|
| **Edge TTS** | 留空 | 不需要 | 免费、免密钥；需本机能访问微软服务 |
| **OpenAI 兼容** | 如 `https://api.openai.com` | 需要 | `POST {base}/v1/audio/speech` |
| **本地 GPT-SoVITS** | 默认 `http://127.0.0.1:9880` | 不需要 | 本地运行，可**克隆音色** |

**在本机跑 GPT-SoVITS（用于音色克隆）**：官方仓库 `RVC-Boss/GPT-SoVITS` 提供 Windows 整合包与手动安装（`pwsh -F install.ps1 --Device CU128 --Source ModelScope`）。**注意**：网页版（WebUI）与本项目用的 **API 不是同一个入口**，需用 API 模式启动：

```bash
python api_v2.py -a 127.0.0.1 -p 9880 -c GPT_SoVITS/configs/tts_infer.yaml
```

然后在 GAL 工具条 `⋯ → 快速克隆` 里选一段 5–10 秒参考音频、填上音频里对应的文字，即可试听并「存为预设」。角色若有微调权重（`.ckpt` / `.pth`），放进角色目录并在「角色管理 → 编辑 → 配音」里选中，合成前会自动切换加载。

> 硬件：推理需 6GB 显存起，微调 8–12GB。**RTX 50 系（Blackwell / sm_120）必须用 cu128 版 PyTorch**，否则报 `CUDA error: no kernel image is available`。

## 🔄 更新版本

本项目把**代码**与**用户数据**分开存放，所以正常更新**不会丢数据**：
- **代码**：`app/`、`web/`、`scripts/`、`resources/`、`main.py`、`server.py`、`requirements.txt`
- **用户数据**：全部在 `data/`（会话 / 密钥 / 画像 / 知识库 / 笔记 / 上传的图片 / 语音模型）；`data/` 与 `docs/` 都已写进 `.gitignore`

**推荐更新方式（二选一）**

1. **Git**：在项目目录执行 `git pull`。`data/` 被忽略，拉取**不会**动你的数据。
   > ⚠️ 千万不要用 `git clean -x` / `git clean -fdx`——它会连同被忽略的 `data/` 一起删掉。
2. **压缩包覆盖**：解压新版本后，**只覆盖代码文件**，保留原来的 `data/` 目录。
   > ⚠️ 新版压缩包里**不应包含 `data/`**。若里面有，先删掉再覆盖，否则会用默认值覆盖你的密钥 / 预设。

**更新前（可选但推荐）** 备份 `data/`（`.browser_profile/` 只是缓存，可不备份）：
```powershell
robocopy "data" "..\_backup_data" /E /XD ".browser_profile"
```

**更新时/后**
- 先**关闭应用窗口**再覆盖（`data/.browser_profile` 被 Edge 占用时会报「文件被占用」）。
- 若 `requirements.txt` 有变化，重新执行 `pip install -r requirements.txt`。

| 工作台（日程 / 任务） | SQLite（标准库 `sqlite3`，WAL）+ 内置重复规则展开（不引入日期库） |
| 图标 | 内嵌 SVG sprite（46 个线条图标，`currentColor` 跟随主题，无需图标库） |
| 语音识别 | sherpa-onnx（本机离线；流式 Zipformer 中文模型，音频不出电脑） |
| 台词朗读 | Edge TTS / OpenAI 兼容 `/v1/audio/speech` / 本地 GPT-SoVITS（音色克隆与微调权重） |
| 文档解析 | pypdf（抽文本）+ pypdfium2（渲染扫描页，自带 PDFium 无需系统组件） |
| 数据 | JSON 本地文件 + Markdown（笔记库）+ SQLite（工作台的任务 / 日程 / 产物） |

## ❓ 常见问题

**Q1：提示"尚未配置聊天 API 密钥"**
点「设置 → 聊天模型」填写密钥并保存。

**Q2：公式显示成代码、代码块没有颜色**
界面依赖 CDN 加载 KaTeX / highlight.js，请确认网络可用（已配置备用 CDN 兜底，不可用时会自动降级但不影响聊天）。

**Q3：自动画像里有些内容不想要**
两种方式：① 在对话中明确否定，AI 会自动删除；② 打开「设置 → 用户画像」手动编辑后保存。

**Q4：关掉控制台窗口后界面还能用吗**
不能。后端服务随该进程运行，请保持控制台窗口开启（最小化即可）。

**Q5：点麦克风没反应 / 提示模型未就绪**
说明还没下载语音模型。执行 `python scripts/fetch_speech_model.py streaming`（约 126MB），下载完**重启服务**再试。首次点麦克风需在浏览器里允许麦克风权限。
开了「语音输入降噪」还提示未就绪时，再执行 `python scripts/fetch_speech_model.py denoise`（8.4MB）；想要更准的最终文本，执行 `python scripts/fetch_speech_model.py final`（155MB）。

**Q6：Agent 说无法读取 / 写入文件**
先确认已点「Agent」并选好**沙箱目录**；AI 只能访问沙箱内的路径（越界、`.git`/`.venv`/`data/` 等会被拒绝）。若选了目录仍不行，重启服务并 `Ctrl+F5` 强刷。

**Q7：语音识别不准**
① 确认已下 `final` 模型（停止后会用 SenseVoice 精修，明显更准；未下载则只有流式结果）；② 嘈杂环境打开「语音输入降噪」；③ 开启「AI 矫正」修标点与错别字（但改不了听错的内容）。

**Q8：更新版本会不会丢数据**
只要按「🔄 更新版本」里的方式——**只覆盖代码、不动 `data/`**——就不会丢。唯一的两个坑：`git clean -x`、以及「拿来覆盖的压缩包里含 `data/`」。

**Q9：聊天里发送的图片存在哪**
存在 `data/uploads/<会话>/`，并按需加载；撤回 / 删除消息、删除或清空会话时会连同图片一起清理。

**Q10：GAL 模式的角色从哪来 / 音色怎么克隆**
角色放在 `data/gal/characters/<id>/`，可在工具条 `⋯ → 角色管理` 里「新建」或「导入文件」（支持本项目的 `.char` 与 Shinsekai 的角色包）。音色克隆需要**本机跑一个 GPT-SoVITS 服务**（见「配置说明 → 台词朗读与音色克隆」）；只用免费的 **Edge TTS** 则不需要任何本地服务。

**Q11：GAL 里排版乱了 / 输出好像不是一段一段**
先 `Ctrl+F5` **强刷**（改了前端 JS/CSS 后尤其需要）。逐字速度在「设置 → GAL 演出 → 打字机」调（8–120 字/秒，全程线性生效）；想要「一次只显示一句」可把「对白展示」换成「单行推进」。若模型这一轮没按演出格式输出，程序会自动把它**按纯文本逐段兜底**推送，打字机不会失效。

**Q12：上传 PDF 提示解析失败 / 读不到内容**
① 先确认依赖已装：`pip install -r requirements.txt`（PDF 需要 `pypdf` 与 `pypdfium2`）。
② 如果是**扫描件**（整页是图片、文字不可选中），程序会自动逐页渲染并交给视觉模型识别——需要先在「设置 → 聊天模型」或「视觉模型」里配好**支持视觉**的密钥。
③ 扫描件很长时默认只识别**前 60 页**（避免一次烧掉太多额度）。
④ 也可以在「Agent」沙箱里让 AI 用 `read_file` 读 PDF（只抽文本层，扫描件读不到）。

**Q13：图寻游戏的照片从哪来 / AI 对手好像看不见图**
照片与**拍摄点的真实经纬度**都来自 **Panoramax 开放街景图库**（免密钥，但**需要联网**），项目本地不维护图片与坐标数据集。所以：① 断网开局会提示「取题失败」，恢复网络后点照片上的「重试」或右下角「换一题」即可；② 图源偶发不可达时，照片位置会出现「换一题」按钮。AI 对手要**真正看图**才能判断位置 —— 需要配好「视觉模型」密钥；没配时会退用「聊天模型」（前提是该模型支持图像），两条通道都不可用就只能在一批候选区域里**盲猜**，界面上会如实标注「盲猜」而不是假装认出了地方。AI 看图的耗时通常在**十几到几十秒**（模型要把整张图读完再推理），多位 AI 是**并行**发起的，不必等前一位结束。

**Q14：图寻界面在窄窗口下被挤成一列 / 想放大看照片细节**
视口窄于 1160px 时，图寻页会自动从「左题面 / 右地图」改为**上下堆叠**，并由大厅区域自己上下滚动（左侧会话栏不会被顶出屏幕）——窗口拉宽就回到两栏。想看照片细节：**点照片本身**（或它右上角的放大镜）开全屏大图，滚轮以光标为锚点缩放、按住拖动平移、双击在「适应窗口 / 原始尺寸」间切换，`Esc` / 图片外轻点 / ✕ 关闭。用的是 2048px 原图，路牌、车牌、门牌这类细节都能看清。

**Q15：工作台的任务为什么停在「待确认」**
这是有意的安全设计：任务里涉及**写文件、建日程、改日程**等写操作时，第一次不会自动执行，而是把该步骤标成「待确认」并暂停任务。打开任务详情点「确认执行」才会继续。读操作（列目录、读文件、查日程）会直接跑。若想全部自动执行，目前不提供一键关闭——避免误删文件。

**Q16：工作台会动到我原来的聊天记录吗**
不会。任务 / 日程 / 产物写在新的 `data/assistant.db` 里；`sessions.json`、`config.json`、知识库与笔记都保持原样。删掉 `assistant.db` 只会清空工作台数据，不影响聊天。

**Q17：工作流到点了没执行**
定时 / 事件触发都依赖**程序正在运行**（和「AI 主动聊天」一样）。另外检查三点：① 工作流是否处于「启用」；② 定时的时间与星期是否填对（0=周一，留空=每天）；③ 是否刚改过系统时间或休眠唤醒——调度器每 15 秒扫一次，唤醒后会补跑当次。手动点「运行」可以立刻验证动作配置是否正确。

**Q18：记忆里为什么默认看不到知识库/画像/笔记**
「记忆」默认只显示**手动记忆与任务结果**，避免和侧栏入口重复。要全局搜索时勾选「包含知识库 / 画像 / 笔记」；这些条目是**只读镜像**：知识库/画像条目可以点「打开来源」跳到图谱节点，笔记条目会直接打开对应笔记。编辑请回「知识库」「设置 → 用户画像」或「笔记库」。添加记忆时可以选择写入画像/会话/知识库；知识库、笔记或会话改动后索引会自动更新，不需要手动点「重建索引」。

**Q19：设置里的旧提醒去哪了**
启动时会自动并入工作台「今日」，标记「旧提醒」；背后的 Windows 计划任务保留，所以**程序关着也能弹**。停用的提醒仍留在设置页，启用后下次启动会迁移。新提醒建议直接在工作台「＋ 日程」或对话里创建。

**Q20：知识库弹窗能搜全部记忆吗**
搜索框右侧有「本库 / 全部记忆」切换。选「全部记忆」会跨画像、知识库、会话做全局搜索，点结果可直接跳到对应节点；「本库」仍是原来的当前库内定位。

**Q21：AI 改了文件，去哪里看它到底改了什么**
看助手回复下方那张变更卡：待审查时会显示**文件名 + 完整路径 + 增删行数**，点文件名会在编辑器区打开单栏 inline diff（绿增红删、带行号），顶部可「撤销 / 保留」，多个文件用 `1/N` 翻页；卡片底部也有「全部撤销 / 全部保留」。快捷键：`Ctrl+Backspace` 撤销、`Ctrl+Enter` 保留。Solo 模式没有编辑器时，会用同样的审阅弹窗展示。若卡片已经不在（例如刷新过页面），可以点对应工具卡上的「查看变更」重新打开；但**重启程序后快照会失效**，旧改动只能看到文件当前内容。
