# Galgame_monster

图形化 AI 交互平台 —— 智能聊天 + 图像识别 + 用户画像 + 文件 Agent + GAL 演出模式

---

## 📖 项目简介

**Galgame_monster** 是一个本地运行的图形化 AI 交互平台。界面使用 Web 技术（HTML/CSS/JS）渲染，
由 Python 提供本地后端服务，并以「应用模式窗口」打开——没有地址栏与标签页，观感与独立桌面程序一致。

核心设计理念：**让 AI 主动适应用户，而不是让用户反复调教 AI**。

界面分三种模式：**Solo**（以对话为主）、**IDE**（VS Code 风格工作区）、**GAL**（把对话演成 Galgame 演出）。

## ✨ 主要功能

### 交互体验
| 功能 | 说明 |
|------|------|
| **流式输出** | 回复逐字显示，可随时点「停止」中断，已收到的内容会保留 |
| **Markdown 渲染** | 标题、粗体、列表、引用、表格、分割线 |
| **代码块** | 语法高亮 + 语言标签 + 一键复制 |
| **LaTeX 公式** | 聊天中的数学公式用 KaTeX 实时排版 |
| **多会话管理** | 左侧会话栏：新建 / 切换 / 双击重命名 / 删除，各自独立历史 |
| **消息操作** | 用户消息可「撤回」（连同后续回复移除）或「修改」后重发；AI 回复可「重新发言」；「选择文本」切换源码视图，便于复制 Markdown / LaTeX 源码 |
| **图片输入** | 按钮上传、`Ctrl+V` 粘贴、拖拽到窗口；发送后**在聊天记录里显示缩略图**（点击放大） |
| **语音输入** | 点「🎤 语音输入」**边说边出字**（本机流式识别，音频不出电脑）；停止后用离线模型（SenseVoice）**两遍精修**，最终文本更准；可开「🎛 降噪」（本机 DPDFNet 流式去背景噪声）；结束后可选**AI 矫正**（补标点/纠错别字/去口癖），矫正结果可一键「撤回原文」 |
| **深浅色主题** | 默认**浅色**，一键切换立即生效；**应用窗口标题栏跟随主题** |
| **IDE / Solo 模式** | 左侧栏顶部切换：**Solo**＝以对话为主；**IDE**＝ **VS Code 风格**工作区（活动栏 / 侧边栏文件树 / 多标签编辑器 / 状态栏），内置 **Monaco**（VS Code 同款，本地内置离线可用），`Ctrl+S` 保存、`Ctrl+P` 快速打开、`Ctrl+Shift+P` 命令面板，支持沙箱内搜索与 UTF-8/GBK 自动识别。**可一键在本机 VS Code 中打开当前沙箱**，并能只读导入 VS Code 的设置与扩展清单 |
| **设置面板** | 左侧 **12 个分类**（接入与密钥 / 对话行为 / 记忆与学习 / 外观与演出 / 快捷键 / 说明），顶部**搜索框**输入关键词即可直达设置项并高亮；支持 **`Esc` 关闭 · `Ctrl+S` 保存 · `←`/`→` 切换分类**；「快捷键」分类列出全部按键及其生效条件 |

### GAL 演出模式
| 功能 | 说明 |
|------|------|
| **舞台演出** | 背景 + 立绘 + 对白框 + 选项的 Galgame 式界面；三套演出主题（樱粉 / 夜蓝 / 和风纸），主题作用于**全部 UI**（含弹窗与提示），应用窗口标题栏也跟随 |
| **逐段对白** | AI 把一轮话拆成若干短段，**边生成边逐段显示**（打字机 + 逐段朗读）；逐字速度可调（**8–120 字/秒，全程线性生效**）；可切「逐段追加（可回看）」或「单行推进（点一下下一句）」；输出时对白框**自动贴底**。模型偶尔不按演出格式输出时，会自动改按纯文本逐段兜底，**逐字效果不会丢** |
| **旁白与场景** | 支持 `NARR` 旁白段（不朗读）；AI 每轮会先交代场景，进入新一幕时也会把该幕的场景描述作为旁白推进对话框 |
| **推进与快捷键** | 空格 / 回车 / 点击舞台推进（打字中先补全）· 按住 `Ctrl` 快进 · `A` 自动播放（**每句播完停 1.5 秒**再切下一句）· `↑` 打开回顾 · `Esc` 逐层关面板 |
| **选项** | AI 每轮可给 2–4 个选项，**等本轮最后一段对白完全显示完才出现**（不会在你还没读完/还没就绪时就能点到）；选定后选项**淡出消失**并随即发送。想自由发言直接用底部输入框 |
| **角色与素材** | 角色即目录（`data/gal/characters/<id>/`）：人设 / 立绘（可绑情绪标签与台词音频）/ 主题色 / 剧本 / 配音预设；支持 `.char`(zip) 导入导出，并**兼容 Shinsekai 的 `character.yaml`** |
| **台词朗读（TTS）** | 三种后端：**Edge TTS**（免费免密钥）/ OpenAI 兼容 `/v1/audio/speech` / **本地 GPT-SoVITS**；每个角色可存多套音色预设，工具条一键切换 |
| **音色克隆** | `⋯ → 🎙 快速克隆`：给一段 5–10 秒参考音频 + 参考文本即可克隆音色（GPT-SoVITS 零样本）；有微调权重（`.ckpt` / `.pth`）的角色会在合成前自动切换加载 |
| **AI 自动写剧本** | 开启后由 AI 依据「角色设定 + 用户画像」编写**分幕大纲**，再**逐幕展开**推进剧情，最后一幕自动收束为结局 |
| **关键词特效** | 台词里写 `*闪光*` / `*震动*` / `*黑屏*` / `*淡入*`（或 `【…】`）触发 CSS 动画与音效；词表与音效可自定义（`data/gal/effects/`） |
| **其它** | 对话回顾面板；角色管理（卡片 / 搜索 / 删除）；可关的「沉浸式」思考与行为提示；剧本按会话独立保存 |

### AI 能力与画像
| 功能 | 说明 |
|------|------|
| **智能聊天** | 任意 OpenAI 兼容接口，支持多轮对话记忆 |
| **图像识别** | 支持 DashScope 原生协议与 OpenAI 兼容视觉接口；可改用**聊天模型**识图（开关切换，聊天模型自带视觉时） |
| **账户余额** | 在设置面板查看各接口的账户余额（内置 DeepSeek，其它厂商可填自定义余额地址） |
| **多套 API 预设** | 地址 + 模型 + 密钥打包成预设，随时切换服务商 |
| **用户画像（手动）** | 自由设置回答规则（如"回答数学题先给结论再给证明"） |
| **用户画像（AI 自主记录）** | AI 在**主对话里直接读写**画像（明文要求记录/删除也会执行），写入后回复下方有「已更新记忆」标记且可撤销；可随时在知识图谱中查看/修改 |
| **知识库与记忆** | 可视化的知识图谱（vis-network，可拖拽/编辑节点）；每个会话独立记忆 + 多个跨会话共享知识库，均可设「AI 可否修改」开关。边**带关系类型**，词表 13 种：相关 / 上下位 / 组成 / 属性 / 同义 / 对立 / 例证 / 因果 / 条件 / 顺承 / 手段 / 目的 / 转折（图上按类型着色）；**相关 / 同义 / 对立 默认画双向箭头**，其余单向，也可手动选方向。节点可设**大小与颜色**（AI 也能设，用于区分重要度 / 分组）；图谱的**斥力 / 中心引力 / 弹簧强度 / 线段长度**可拖动调节并随该库保存 |
| **文件 Agent（沙箱）** | 为会话指定一个目录作为**沙箱**后，模型可在其中自主 `列目录 / 读文件 / 搜索 / 写文件 / 改文件 / 建目录 / 移动 / 删除`（**不提供命令行工具**）；每次写操作生成工具卡片，可一键**撤回**。需要你决策时会在对话里弹**提问卡**，你回答后 AI **原地继续**。另有会话级「📤 读沙箱外」开关（**只读**：开启且你明确要求时，可读沙箱外的绝对路径；写入仍只在沙箱内） |
| **对话上限** | 输入框上方实时显示 token 占用进度条 + 剩余量，剩余不足 10% / 5% 时提醒，接近上限自动压缩较早的历史 |
| **本地存储** | 配置、会话、画像、知识库、笔记均存本地文件，隐私可控 |

### 笔记库（内置 Obsidian 核心版）
| 功能 | 说明 |
|------|------|
| **本地 Markdown** | 笔记就是 `data/notes/**.md` 普通文件，可用任何编辑器直接打开修改 |
| **文件树** | 文件夹 / 笔记的新建、重命名、删除；搜索标题与全文并跳转 |
| **编辑 · 预览** | 编辑与渲染预览一键切换；Markdown / LaTeX / 代码高亮与聊天一致 |
| **双向链接** | `[[笔记名]]`、`[[笔记名\|别名]]`、`[[笔记名#锚点]]`；点击跳转，未创建的显示为橙色虚线、点一下即新建 |
| **关系图谱** | 笔记为节点、双链为边，可拖拽缩放；点节点打开笔记；未创建的链接显示为虚线「幽灵节点」 |
| **反向链接** | 右侧列出"哪些笔记提到了这一篇"，点击直接跳过去 |
| **重命名不断链** | 重命名笔记时，其它笔记里的 `[[旧名]]` 会自动同步更新（与 Obsidian 一致） |

> 说明：内置笔记库是**自主实现**的 Obsidian 核心功能（文件管理 + 双链 + 图谱），
> 不含插件系统、主题、模板与同步；Obsidian 本身闭源，两者无代码关系。

### 文件 Agent（沙箱）
| 功能 | 说明 |
|------|------|
| **开启与沙箱** | 点输入区上方「🛠 Agent」，在系统目录框里选一个**沙箱目录**；设置**按会话保存**，可随时更换 |
| **可用的工具** | `list_dir` / `read_file` / `search_files` / `write_file` / `edit_file` / `make_dir` / `move_file` / `delete_file`（**没有命令行工具**） |
| **安全边界** | 只接受**沙箱内**的路径（相对路径推荐，沙箱内的绝对路径也接受）；越界路径直接拒绝；`.git` / `.venv` / `node_modules` / `__pycache__` 与本项目 `data/` **永久禁止访问**；如需读取沙箱外文件，可开启输入区的「📤 读沙箱外」（**只读**、按会话保存，需你明确要求） |
| **改动可撤回** | 每次写操作在对话里生成一张工具卡片，点「撤回」即恢复文件快照 |
| **中途提问** | AI 需要你决策时会弹**提问卡**（可点选项或自己输入），你回答后它**原地继续**，无需重新发消息。**与 Agent 解耦：不开启 Agent、不选沙箱也能用** |
| **编码兼容** | 读取会自动识别 UTF-8 / GBK 等编码，编辑**按原编码写回**，中文文件不乱码 |
| **IDE 工作区** | 切到「IDE」模式时进入 **VS Code 风格**布局：活动栏 + 以**当前会话沙箱为根**的文件树 + Monaco 多标签编辑器 + 状态栏，右侧窄栏仍可对话；支持沙箱内搜索、AI 改动自动刷新并高亮。活动栏「🧩」可在**本机 VS Code 中打开当前沙箱**（用你自己的插件），命令面板可**只读导入** VS Code 设置与扩展清单 |

## 🚀 快速开始

### 1. 安装 Python

需要 Python 3.8 或更高版本。未安装请访问 [python.org](https://www.python.org/) 下载安装。

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

> 界面依赖的 KaTeX / highlight.js 通过 CDN 加载，无需本地安装。

### 3. 下载语音识别模型（可选，仅「语音输入」需要）

语音识别在**本机离线**运行，需先下载中文模型（约 126MB，落在 `data/models/`，不会提交）：

```bash
python scripts/fetch_speech_model.py streaming
```

想做语音**降噪**再下一个小模型（8.4MB，用「🎛 降噪」开关时才需要）：

```bash
python scripts/fetch_speech_model.py denoise
```

想要**更准的最终文本**，再下离线精修模型（155MB，用于「两遍识别」；不下则只用流式结果）：

```bash
python scripts/fetch_speech_model.py final
```

> 网络受限时先设代理：`$env:HTTPS_PROXY="http://127.0.0.1:7897"`（PowerShell）。
> 不下载也能正常使用其它功能，只是点「🎤 语音输入」会提示模型未就绪。

### 4. 运行

```bash
python main.py
```

启动后会自动打开应用窗口。**首次运行**会自动弹出设置，请先填写「聊天模型 → API 密钥」。

退出：关闭应用窗口即可；或在控制台按 `Ctrl+C`。

## ⚙️ 配置说明

> 各功能的实际作用与区别，可在「设置 → **功能说明**」里逐项查看（含深度思考档位的映射差异等）。

### 聊天 API（智能聊天 + 记忆读写）

填写任意 **OpenAI 兼容**接口的地址、模型名与密钥即可。例如：

| 服务 | 接口地址 | 模型名 |
|------|----------|--------|
| DeepSeek 官方 | `https://api.deepseek.com/chat/completions` | `deepseek-flash` |
| 本地 Ollama | `http://localhost:11434/v1/chat/completions` | 你拉取的模型名 |

> 只填 base URL（如 `https://api.deepseek.com`）时会自动补全为 `/v1/chat/completions`。

### 图像 API（图像识别）

支持两种协议，按服务商选择：

- **DashScope 原生**：图片放 `input.messages[].content`，结果取 `output.choices[0].message.content`
  例：阿里云百炼 `qwen-vl-plus` / `qwen-vl-max` / `qwen-vl-ocr`
- **OpenAI 兼容**：图片放 `messages[].content`（`type=image_url`），结果取 `choices[0].message.content`
  例：`deepseek-flash`、GPT-4o、vLLM / Ollama 本地多模态

> 顶部有「**使用聊天模型识别图片**」开关：开启后不再用上面的视觉 API，改由「聊天 API」的模型与密钥识图（要求聊天模型自带视觉能力）。

### 账户余额

- **DeepSeek**：按接口地址自动识别，调用官方 `GET /user/balance`。
- **其它厂商**：若提供余额接口，在「余额查询地址」里填该地址（GET + Bearer 鉴权）；留空且非 DeepSeek 则显示「不支持」。
- 打开设置时自动查询一次，也可点「刷新」手动查询。

### 用户画像

- **手动偏好**：你主动设置的规则，优先级更高，每轮都会注入。
- **自动学习**：AI 在**主对话里直接读写**「用户画像」知识库的节点——明文说「记住 / 删掉那条 / 改一下」会直接执行；它输出的写入指令用户看不到。写入后回复下方会出现「已更新记忆」标记，点「撤销」可回滚；新旧信息矛盾时以更晚、更明确者为准，不会让矛盾条目并存。
- 可随时关闭画像写入，或自定义判断准则（支持 `{current_auto}` `{user_input}` `{ai_reply}` 占位符），详见「设置 → 功能说明」。

### 台词朗读（TTS）与音色克隆

GAL 模式的台词可自动朗读，服务商在「设置 → 语音 / 输入 → 台词朗读」里选：

| 服务 | 地址 | 密钥 | 说明 |
|------|------|------|------|
| **Edge TTS** | 留空 | 不需要 | 免费、免密钥；需本机能访问微软服务 |
| **OpenAI 兼容** | 如 `https://api.openai.com` | 需要 | `POST {base}/v1/audio/speech` |
| **本地 GPT-SoVITS** | 默认 `http://127.0.0.1:9880` | 不需要 | 本地运行，可**克隆音色** |

**在本机跑 GPT-SoVITS（用于音色克隆）**：克隆音色需要一个本地 GPT-SoVITS 服务。官方仓库 `RVC-Boss/GPT-SoVITS` 提供 Windows 整合包（解压后双击 `go-webui.bat` 起网页版）与手动安装（`pwsh -F install.ps1 --Device CU128 --Source ModelScope`）。**注意**：网页版（WebUI）与本项目使用的 **API 不是同一个入口**，需要用 API 模式启动：

```bash
python api_v2.py -a 127.0.0.1 -p 9880 -c GPT_SoVITS/configs/tts_infer.yaml
```

然后在 GAL 工具条 `⋯ → 🎙 快速克隆` 里选一段 5–10 秒的参考音频、填上音频里对应的文字，即可试听并「存为预设」。若角色有微调权重（`.ckpt` / `.pth`），把权重放进角色目录，在「✎ 角色 → 配音」里选中即可——合成前会自动切换加载。

> 硬件参考：推理需 6GB 显存起；微调 8–12GB。**RTX 50 系（Blackwell / sm_120）必须用 cu128 版 PyTorch**，否则会报 `CUDA error: no kernel image is available`。

数据文件说明：所有运行时数据都在 `data/` 目录 —— `config.json`（密钥与预设，**明文**存储于本机）、`sessions.json`（会话）、`user_profile.json`（画像）、`knowledge/`（知识库）、`notes/`（笔记库，普通 `.md` 文件）、`gal/`（GAL 角色 / 背景 / BGM / 特效音）、`uploads/`（聊天图片附件）、`token_usage.jsonl`（用量流水）、`models/`（语音模型）、`.browser_profile/`（应用窗口缓存）。
整个 `data/` 已在 `.gitignore` 中忽略；随项目发布的 `learning_presets.json` 位于 `resources/`。

## 🔄 更新版本

本项目把**代码**与**用户数据**分开存放，所以正常更新**不会丢数据**：
- **代码**：`app/`、`web/`、`scripts/`、`resources/`、`main.py`、`server.py`、`requirements.txt`
- **用户数据**：全部在 `data/`（会话 / 密钥 / 画像 / 知识库 / 笔记 / 上传的图片 / 语音模型）；`data/` 与 `docs/` 都已写进 `.gitignore`，不随项目发布

**推荐更新方式（二选一）**

1. **Git**：在项目目录执行
   ```bash
   git pull
   ```
   `data/` 被忽略，拉取**不会**动你的数据。
   > ⚠️ 千万不要用 `git clean -x` / `git clean -fdx`——它会连同被忽略的 `data/` 一起删掉。

2. **压缩包覆盖**：解压新版本后，**只覆盖代码文件**，保留原来的 `data/` 目录。
   > ⚠️ 新版压缩包里**不应包含 `data/`**。若里面有，先删掉再覆盖，否则会用默认值覆盖你的 `config.json`（密钥 / 预设）等数据。

**更新前（可选但推荐）** 备份 `data/`（`.browser_profile/` 只是缓存，可不备份）：
```powershell
robocopy "data" "..\_backup_data" /E /XD ".browser_profile"
```

**更新时/后**
- 先**关闭应用窗口**再覆盖（`data/.browser_profile` 被 Edge 占用时，覆盖会报「文件被占用」）。
- 若 `requirements.txt` 有变化，重新执行 `pip install -r requirements.txt`。

## ❓ 常见问题

**Q1：提示"尚未配置聊天 API 密钥"**
点「设置 → 聊天模型」填写密钥并保存。

**Q2：公式显示成代码、代码块没有颜色**
界面依赖 CDN 加载 KaTeX / highlight.js，请确认网络可用（已配置备用 CDN 兜底，不可用时会自动降级但不影响聊天）。

**Q3：自动画像里有些内容不想要**
两种方式：① 在对话中明确否定，AI 会自动删除；② 打开「设置 → 用户画像」手动编辑后保存。

**Q4：关掉控制台窗口后界面还能用吗**
不能。后端服务随该进程运行，请保持控制台窗口开启（最小化即可）。

**Q5：点「🎤 语音输入」没反应 / 提示模型未就绪**
说明还没下载语音模型。执行 `python scripts/fetch_speech_model.py streaming`（约 126MB），下载完**重启服务**再试。首次点麦克风需在浏览器里允许麦克风权限。开了「🎛 降噪」还提示未就绪时，再执行 `python scripts/fetch_speech_model.py denoise`（8.4MB）；想要更准的最终文本，执行 `python scripts/fetch_speech_model.py final`（155MB，两遍识别）。

**Q6：Agent 说无法读取 / 写入文件**
先确认已点「🛠 Agent」并选好**沙箱目录**；AI 只能访问沙箱内的路径（越界、`.git`/`.venv`/`data/` 等会被拒绝）。若选了目录仍不行，重启服务并 `Ctrl+F5` 强刷。

**Q7：语音识别不准**
① 确认已下 `final` 模型（停止后会用 SenseVoice 精修，明显更准；未下载则只有流式结果）；② 嘈杂环境打开「🎛 降噪」；③ 在「设置 → 语音输入」开启「AI 矫正」修标点与错别字（但改不了听错的内容）。

**Q8：更新版本会不会丢数据**
只要按「🔄 更新版本」里的方式——**只覆盖代码、不动 `data/`**——就不会丢。`data/` 已在 `.gitignore` 忽略，`git pull` 不会删改它。唯一的两个坑：`git clean -x`、以及「拿来覆盖的压缩包里含 `data/`」。

**Q9：聊天里发送的图片存在哪**
存在 `data/uploads/<会话>/`，并按需加载；撤回 / 删除消息、删除或清空会话时会连同图片一起清理。

**Q10：GAL 模式的角色从哪来 / 音色怎么克隆**
角色放在 `data/gal/characters/<id>/`，可在工具条 `⋯ → ⚙ 角色管理` 里「＋ 新建」或「📦 导入文件」（支持本项目的 `.char` 与 Shinsekai 的角色包）。音色克隆需要**本机跑一个 GPT-SoVITS 服务**（见「⚙️ 配置说明 → 台词朗读与音色克隆」），再在 `⋯ → 🎙 快速克隆` 里给参考音频即可；若只用免费的 **Edge TTS** 则不需要任何本地服务。

**Q11：GAL 里排版乱了 / 输出好像不是一段一段**
先 `Ctrl+F5` **强刷**（改了前端 JS/CSS 后尤其需要）。逐字速度在「设置 → GAL 演出 → 打字机」调（8–120 字/秒，**全程线性生效**）；想要「一次只显示一句」可把「对白展示」换成「单行推进」。若模型这一轮没按演出格式输出，程序会自动把它**按纯文本逐段兜底**推送，打字机不会失效。
